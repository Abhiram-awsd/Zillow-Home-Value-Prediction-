# Zillow Home Value Prediction

A full-stack housing value prediction application integrating a React frontend, Express API, Python machine-learning inference service, and MongoDB-backed prediction history.

## Project status

The source research project is a Jupyter Notebook. The application will preserve the original trained preprocessing and model pipeline behind a Python inference service, with the React frontend communicating through an Express API. Predictions should only be presented as real model outputs after the pipeline is integrated and validated.
